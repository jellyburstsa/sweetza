## Stock status
- Available products use a subtle green treatment and a green **✓ Available** badge.
- Out-of-stock products use a subtle red treatment and red **Out of Stock** badge.
- Quantity controls and Add to Cart are disabled for out-of-stock products.
- The cart logic also rejects out-of-stock products even if the add function is triggered manually.
